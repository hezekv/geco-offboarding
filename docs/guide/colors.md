# Color Styling

Our palette is designed for professional HR environments, using a primary Teal/Blue brand identity with clear semantic colors for status and actions.

## Brand Colors
| Name | Hex | Tailwind Class | Usage |
|---|---|---|---|
| Brand Primary | `#12607A` | `bg-[#12607A]` | Primary buttons, active states, brand marks |
| Brand Hover | `#198754` | `hover:bg-[#198754]` | Success actions, primary button hover |
| Brand Dark | `#0E4C63` | `bg-[#0E4C63]` | Deep hover states, active nav items |

## Semantic / Status Colors
| Name | Hex | Tailwind Class | Usage |
|---|---|---|---|
| Completed / Success | `#177245` | `bg-[#177245]` | Completed tasks, success badges |
| In Progress / Info | `#0E5A8C` | `bg-[#0E5A8C]` | Active tasks, info badges, progress bars |
| Pending / Warning | `#B0761A` | `bg-[#B0761A]` | Pending tasks, warning badges |
| Danger / Error | `#C24152` | `text-[#C24152]` | Delete buttons, error states, archive actions |
| Draft / Neutral | `#E4EEF6` | `bg-[#E4EEF6]` | Draft status pills, light info backgrounds |

## Surface & Text Colors
| Name | Hex | Tailwind Class | Usage |
|---|---|---|---|
| Page Background | `#EFF3F7` | `bg-[#EFF3F7]` | Main app background |
| Card Background | `#FFFFFF` | `bg-white` | Tables, modals, profile cards |

| Borders | `#D5DEE8` | `border-[#D5DEE8]` | Inputs, cards, dividers |
