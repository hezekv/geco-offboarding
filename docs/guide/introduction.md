# Introduction

Welcome to the **GECO Asia HR Business Partner Portal** Design System. This documentation serves as the single source of truth for UI/UX patterns, styling tokens, and component usage across the Offboarding application, based on the official UI/UX practical requirements.

## Design Philosophy
- **Clarity & Readability**: High contrast text, clear visual hierarchy, and generous whitespace.
- **Consistency**: Reusable Tailwind CSS utility classes ensure every button, input, and card behaves predictably.
- **Accessibility**: Focus rings, semantic HTML, and ARIA attributes are baked into every component.
- **Realistic Workflows**: Components are designed around actual HR and Consultant tasks (e.g., hover choreography for table actions, lifecycle-aware buttons).

## Tech Stack
- **Framework**: Vue 3 (Composition API)
- **Styling**: Tailwind CSS
- **Icons**: Custom SVG Sprite (`<AppIcon>`) + Lucide Vue Next
- **Documentation**: VitePress
