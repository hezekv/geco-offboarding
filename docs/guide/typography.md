# Typography

We use the system UI font stack for maximum legibility and native feel. Hierarchy is established through font weight and size, not just color.

## Font Scale
| Size | Tailwind Class | Line Height | Usage |
|---|---|---|---|
| `12px` | `text-xs` | `leading-tight` | Badges, meta labels, helper text |
| `13px` | `text-[13px]` | `leading-snug` | Table cells, button text, file chips |
| `14px` | `text-sm` | `leading-snug` | Body text, input values, default text |
| `16px` | `text-base` | `leading-relaxed` | Sub-requirement titles, modal body |
| `18px` | `text-lg` | `leading-tight` | Section headings, modal titles |
| `24px` | `text-2xl` | `leading-tight` | Page titles, consultant names |
| `21px` | `text-[21px]` | `leading-none` | Metric card large numbers |

## Font Weights
- **Medium (`500`)**: `font-medium` – Used for labels, meta text, and secondary buttons.
- **Semibold (`600`)**: `font-semibold` – Used for table headers, card titles, and primary data values.
- **Bold (`700`)**: `font-bold` – Used for brand names, primary headings, and key metrics.
